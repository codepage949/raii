# raii

`raii`는 Linux의 Netlink 인터페이스를 활용하여 특정 네트워크 인터페이스의 기본 라우트의 우선순위를 일시적으로 올리는 CLI 도구입니다.

## 동작

지정된 네트워크 인터페이스의 기본 라우트를 별도의 라우팅 테이블(ID: 112)에 복제하고, 해당 테이블을 참조하도록 우선순위 112의 정책 라우팅 룰을 추가한 뒤 대기하며, 사용자 입력 시 해당 라우트와 룰을 삭제하여 원래 상태로 복원합니다.

## 기술 스택

- **언어**: Rust
- **네트워크 / 커널 통신**: rtnetlink
- **대상 환경**: Linux

## 실행 방법

네트워크 라우팅 및 룰을 변경해야 하므로 관리자 권한이 필요합니다.

```bash
sudo raii <인터페이스_이름>

# 실행 예시
sudo raii eth0
```

## 특이 사항

- **실행 권한 요구사항**:
  - Netlink 라우팅 테이블 및 정책 룰을 등록/삭제해야 하므로 `root` 권한 또는 `CAP_NET_ADMIN` capability가 반드시 필요합니다.
- **고정된 식별자**:
  - 라우팅 테이블 ID: `112` (`TABLE_ID`)
  - 정책 라우팅 우선순위: `112` (`PRIORITY`)
- **비정상 종료 시 복원**:
  - `SIGINT`(`Ctrl+C`) 또는 강제 종료 신호로 프로그램이 중단되면 이후의 정리 함수가 호출되지 않아 테이블 112의 라우트 및 룰이 시스템에 잔류할 수 있습니다.
  - 다만 프로그램 시작 부분에 사전 정리 루틴이 포함되어 있어 프로그램을 다시 실행하면 잔여 설정을 자동으로 초기화할 수 있습니다.
